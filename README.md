One word describing the boss: **teflon**.

The boss nothing sticks to. Blame, missed deadlines, bad calls — everything slides off him while it sticks to everyone else. One word, no caption needed, and every office, kitchen and warehouse has met him.

## How to run

```sh
python3 main.py
```

This writes exactly one word to `/output/entry.txt` (`teflon`, 6 bytes, no trailing newline). Pure Python standard library, deterministic — two runs produce byte-identical output.
